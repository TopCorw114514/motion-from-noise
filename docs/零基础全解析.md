## 0. 先记住一件事

**本项目不是在“画一条漂亮的曲线”，而是在模拟一个真实工程问题：**
传感器读到的数字总是带噪声，我们要用数学方法把“真实情况”还原出来。

整条故事线只有四步：

1. 制造一个“有标准答案”的实验（模拟真实运动 + 噪声）；
2. 用卡尔曼滤波去噪声；
3. 用一个简单方法（滑动平均）做对照组；
4. 用数字证明“卡尔曼更好”，并把运动参数反推出来。

---

## 1. 为什么要做这个项目？（生活比喻）

想象你在看远处一辆匀速减速的小车：

- 你真正想知道的是：它现在在哪、速度是多少；
- 但你手上只有一台“很抖”的测距仪，读数一会儿 1.02，一会儿 0.93；
- 如果直接把抖动读数拿去用，算出来的速度会忽大忽小，完全没法用。

卡尔曼滤波做的事是：

> 我既相信“物理规律”（小车不会瞬间瞬移），也相信“传感器读数”（虽然有点噪声），
> 我把两者按可信程度加权，得到比任何一个单独来源都更准的估计。

这就是“智能感知”最核心的一句话：**从带噪声的数据里还原真实状态。**

---

## 2. 真实世界中的应用

这个原理可以用在很多地方：

- 手机导航：GPS 信号抖动时，用卡尔曼平滑位置和速度；
- 无人机 / 机器人：融合陀螺仪和加速度计，估计姿态角；
- 自动驾驶：把多个传感器（激光雷达、摄像头、轮速计）融合成一条稳定轨迹；
- 物理实验：光电门、超声波测距仪读出的数据先滤波再分析；
- 本项目未来可以直接接 MPU6050 等真实传感器。

所以它虽然是仿真数据，但背后的算法是“真东西”。

## 5. sensor_simulator.py：第 1 步，造数据

### 5.1 `SimulationConfig`（模拟参数）

```python
@dataclass
class SimulationConfig:
    dt: float = 0.02           # 每隔多少秒采一次样
    duration: float = 5.0      # 一共模拟几秒
    x0: float = 1.0            # 初始位置（米）
    v0: float = 0.6            # 初速度（米/秒）
    acceleration: float = -0.4 # 加速度（米/秒²）
    noise_std: float = 0.08    # 噪声标准差（米）
    seed: int = 42             # 随机种子
```

- `dt` 读作“delta t”，表示时间间隔；
- `noise_std` 的 std 是 standard deviation（标准差），可以粗略理解成“噪声有多野”；
- `seed` 是随机种子：同一个 seed，跑出来的噪声完全相同，便于复现实验结果。

### 5.2 `simulate_position_sensor(config)`

```python
def simulate_position_sensor(config: SimulationConfig) -> SimulationResult:
```

**作用**：根据上面的配置生成一整组实验数据。

**函数内部做了三件事：**

1. 生成时间轴：
```python
times = np.arange(0.0, config.duration, config.dt)
```
含义：从 0 开始，每 `dt` 秒取一个点，一直到 `duration`。0.02 秒一个点、共 5 秒，就有 250 个点。

2. 用物理公式算“真实轨迹”：
```python
true_position = x0 + v0*t + 0.5*a*t²
```
这就是高中匀加速运动公式。

3. 加噪声生成“传感器读数”：
```python
measured = true_position + 随机噪声
```

**返回的 `SimulationResult` 里有什么？**

| 字段 | 含义 |
|---|---|
| `times` | 每个采样时刻 |
| `true_position` | 真实位置（标准答案） |
| `true_velocity` | 真实速度 |
| `true_acceleration` | 真实加速度 |
| `measured_position` | 传感器读数（真实 + 噪声） |
| `noise_std` | 噪声标准差 |

## 6. kalman_filter.py：第 2 步，核心算法

### 6.1 状态向量：我们要估计什么

把物体某一时刻的“真实状态”写成：

```text
X = [位置 x, 速度 v, 加速度 a]
```

例如 `X = [1.0, 0.6, -0.4]` 表示：在 1 米处、以 0.6 米/秒运动、加速度 -0.4 米/秒²。

### 6.2 类和方法总览

```python
class ConstantAccelerationKalman:
    def __init__(self, dt, measurement_noise_std, process_noise=0.0001)
    def _initialize(self, first_measurement)
    def step(self, measurement)
    def filter_all(self, measurements)
```

### 6.3 `__init__`：创建滤波器时做准备

**语法：**

```python
kf = ConstantAccelerationKalman(
    dt=0.02,
    measurement_noise_std=0.08,
    process_noise=0.0001,
)
```

`__init__` 里准备了四个“数学工具”：

#### F：状态转移矩阵

它回答：“如果没有任何新测量，0.02 秒后物体会变成什么样？”

匀加速运动的一步公式：

```text
x_new = x + v·dt + 0.5·a·dt²
v_new = v + a·dt
a_new = a
```

代码中的矩阵：

```python
self.F = np.array([
    [1.0, dt, 0.5 * dt * dt],
    [0.0, 1.0, dt],
    [0.0, 0.0, 1.0],
])
```

如果你还不会矩阵，不要怕：**矩阵只是把上面三个算式打包成一张表格**，`F @ X` 就是按表计算新状态。

#### H：测量矩阵

回答：“传感器能看到状态里的哪个量？”

本项目传感器只能测位置，所以：

```python
self.H = np.array([[1.0, 0.0, 0.0]])
```

`H @ X` 的结果就是 `1*x + 0*v + 0*a = x`，也就是“预测的测量值 = 位置”。

#### R：测量噪声方差

```python
self.R = np.array([[measurement_noise_std**2]])
```

`**2` 是平方。R 越大 = 越不相信传感器。

#### Q：过程噪声

```python
g = np.array([[0.5*dt*dt], [dt], [1.0]])
self.Q = process_noise * (g @ g.T)
```

它是“模型也不完美”的余地。Q 越大 = 越相信新的测量能修正模型错误。

### 6.4 `_initialize`：给滤波器一个起点

```python
def _initialize(self, first_measurement: float):
    self.state = np.array([first_measurement, 0.0, 0.0])
```

- 名字前有下划线 `_` 表示“内部方法，通常不手动调用”；
- 第一个读数告诉我们位置，所以位置直接用它；
- 速度和加速度还不知道，先设 0，让滤波器后面自动收敛。

### 6.5 `step`：核心中的核心（处理一个测量值）

```python
def step(self, measurement: float):
```

**第一步 预测（Predict）**

```python
self.state = self.F @ self.state
self.covariance = self.F @ self.covariance @ self.F.T + self.Q
```

- `@` 是 NumPy 里的矩阵乘法；
- 第一行：用运动模型猜测现在状态；
- 第二行：同时更新“我对估计有多不确定”。

**第二步 更新（Update）**

```python
innovation = measurement - (self.H @ self.state)[0]
```

意思是：**这次传感器读到的，比模型预测的多（或少）了多少。**

```python
gain = (self.covariance @ self.H.T)[:, 0] / innovation_covariance
```

`gain` 就是卡尔曼增益：一个 0~1 之间的“信任分配器”。

```python
self.state = self.state + gain * innovation
```

翻译成人话：

> 最终估计 = 模型预测 + 信任比例 × (传感器告诉我该补多少)

### 6.6 `filter_all`：处理一整串测量

```python
def filter_all(self, measurements: np.ndarray) -> dict:
```

**作用**：把 250 个测量值逐个喂给 `step()`，并收集每一拍的位置、速度、加速度估计。

```python
for i in range(1, len(measurements)):
    state = self.step(measurements[i])
    positions[i], velocities[i], accelerations[i] = state
```

返回值是字典：

```python
{
    "position": 位置数组,
    "velocity": 速度数组,
    "acceleration": 加速度数组,
}
```

字典就是“带名字的盒子”，调用方用 `result["position"]` 取出位置数组。

## 7. baseline_filters.py：对照组（滑动平均）

### 7.1 为什么需要对照组

只有对照组，才能证明“卡尔曼不是自己说自己好”。

### 7.2 函数

```python
def causal_moving_average(signal: np.ndarray, window_size: int = 21) -> np.ndarray:
```

参数：

- `signal`：原始信号；
- `window_size`：取多少个点做平均。

**“因果”** 的意思是：计算当前点时，只能看现在和过去，不能偷看未来（真实传感器必须实时）。

做法是让一个“长度为 window_size 的平均窗口”从数据上滑过去，每滑一格输出一个平均值。

代码里的 `np.pad` 是为了处理开头没有足够历史数据的问题；
`np.convolve` 可以理解成“窗口滑动求和”。

## 8. estimator.py：算误差 + 反推参数

### 8.1 `rmse(estimated, truth)`

```python
def rmse(estimated: np.ndarray, truth: np.ndarray) -> float:
    return float(np.sqrt(np.mean((estimated - truth) ** 2)))
```

- `estimated - truth`：每个点的误差；
- `**2`：平方，消除正负；
- `mean`：平均；
- `sqrt`：开根号还原单位。

结果单位是“米”，数字越小越好。

### 8.2 `fit_motion_parameters(times, positions)`

```python
def fit_motion_parameters(times, positions) -> dict:
    p2, p1, p0 = np.polyfit(times, positions, 2)
    return {
        "x0": p0,
        "v0": p1,
        "acceleration": 2*p2,
    }
```

`np.polyfit(times, positions, 2)` 在找一条最贴合数据的二次曲线：

```text
x(t) = p2·t² + p1·t + p0
```

对比物理公式：

```text
x(t) = 0.5·a·t² + v0·t + x0
```

所以：

- `p0` = 初始位置 x0
- `p1` = 初速度 v0
- `2*p2` = 加速度 a
